# EduForAll - Quality Education (SDG 4)

A simple, responsive frontend website developed to promote **United Nations Sustainable Development Goal 4 (Quality Education)**. This project was created as part of a **Social Internship** to spread awareness about the importance of inclusive and equitable education through an interactive web interface.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Clean and modern user interface
- Hero section with smooth scrolling
- About SDG 4 section
- Why Education Matters cards
- Learning Resources with interactive "Read More" popups
- Animated statistics counters
- Interactive quiz with instant score calculation
- Contact Information section
- Scroll-to-top button
- Active navigation highlighting

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)

## Project Structure

```
EduForAll/
```

## How to Run

1. Download or clone this repository.
2. Ensure all files are in the same folder.
3. Open `index.html` in any modern web browser.

No installation, backend, or additional dependencies are required.

## Purpose

The primary objective of this project is to create awareness about **Quality Education (SDG 4)** by presenting educational information in a simple, interactive, and visually appealing manner.
